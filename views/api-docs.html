API Documentation

Our REST-compatible API lets your software interact directly with our activation server. Automate phone number requests and OTP retrieval with any HTTP client.

Base Endpoint URL

All requests go to this endpoint via GET parameters:

{{SITE_URL}}/stubs/handler_api.php

🔑 Authentication

All requests must include your api_key parameter.

💰 Get Balance
❱

Retrieve your current account balance

Endpoint
{{SITE_URL}}/stubs/handler_api.php?api_key=$api_key&action=getBalance
Parameters
FieldTypeReqDescription
actionStringYesMust be getBalance
api_keyStringYesYour unique API key
Success Response
CodeValue / Description
ACCESS_BALANCE:100.20Current account balance.
Error Responses
CodeDescription
BAD_KEYInvalid API key.
ERRORGeneral server error.
Node.js example
const axios = require('axios');

async function getBalance() {
  try {
    const response = await axios.get('{{SITE_URL}}/stubs/handler_api.php', {
      params: {
        api_key: 'YOUR_API_KEY',
        action: 'getBalance'
      }
    });
    console.log(response.data);
  } catch (error) {
    console.error(error);
  }
}

getBalance();
